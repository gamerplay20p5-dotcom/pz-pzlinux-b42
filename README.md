# PZLinux (B42.21) — versão modificada

Versão modificada do mod **PZLinux** (autor original: Raixxar) para Project Zomboid Build 42.21, versão 0.3.0. Computadores, ATMs e correio conectam uma economia com banco, Mercado Local, Dark Web, contratos, encomendas, bolsa, apostas e hacking.

- 55 opções de Sandbox (PT-BR e EN); módulos ativáveis individualmente.
- Dinheiro vanilla (`Base.Money` / `Base.MoneyBundle`) ou moedas PZLinux: cobre (1), prata (100) e ouro (10000).
- ID do mod: `B42_PZLinux42`.

Documentação: [README_PTBR.md](README_PTBR.md), [README_EN.md](README_EN.md), [SANDBOX_PTBR.md](SANDBOX_PTBR.md).

Instalação: copie `Contents/mods/B42 PZLinux` para `Zomboid/mods` e ative o mod. Crédito do mod original para Raixxar.
